## How to redeem Call of Dragons codes

1. Tap your lord's portrait in the upper-left corner.
2. Open Settings and choose Redeem Gifts.
3. Paste a code into the field and tap Exchange.
4. Collect the gift from your mailbox.

Each code works once per account, so a second lord on another server needs to claim it separately.

## Why might a code fail?

Check capitalization and the deadline first. Some offers have a claim limit or need the latest client version, so update the game if a new code is rejected. Never share your account login with a third-party code site.
