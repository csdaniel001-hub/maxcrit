## How to redeem FC Mobile codes

1. Visit EA's [FC Mobile redemption portal](https://redeem.fcm.ea.com/).
2. Sign in with the EA Account linked to the FC Mobile profile you intend to use.
3. Enter the code, complete any verification requested by the site and submit it.
4. Return to the game and check the inbox for your reward.

EA explains that delivery can take a few minutes. An accepted code and an immediately visible reward are two different things, so allow time for delivery before repeating an attempt. If you have more than one EA Account, confirm the account linked to the correct club before starting.

## What the two rewards offer

FOOTBALLFEAST is particularly relevant to players working on rank upgrades: the reported reward includes Rank Up Points as well as a Draft Voucher. COMINGHOME instead offers an England player in the listed OVR range. The pack description does not guarantee a particular footballer, so do not plan a squad around an assumed pull.

If a code is rejected, check the exact string first. Most EA promotions can be claimed only once, and campaign eligibility may vary. A previously redeemed offer will not generate another pack. Use the official EA site for redemption and avoid any third-party service that requests EA Account credentials. We have omitted older offers whose reported availability has ended.
