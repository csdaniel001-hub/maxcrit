## How to redeem an exchange code

1. Open the game menu and enter Settings.
2. Select Other and locate Exchange Code.
3. Enter one code exactly as shown in the table and submit it.
4. Check your in-game mailbox for the reward.

If the exchange option is missing, complete the tutorial and check the menu again. Do not confuse the exchange screen with a shop purchase or enter your account password into a third-party code finder.

## Which codes should you try first?

Start with 1113HUTUOGO because it carries the larger Echo Jade and Resonating Melody allocation. Then enter 1015QINGZHOU on the same eligible character. Record which offers you have already claimed before switching devices, since a previously accepted code can be rejected on a subsequent attempt.
