## How to redeem BLEACH: Soul Resonance codes

New accounts need to progress through the early story before the Event menu becomes available. The reported unlock is around Stage 1-6, including the school rooftop sequence.

1. Return to the main lobby and tap the Event icon at the top right.
2. Select the Permanent tab, indicated by the infinity symbol.
3. Open Treasure Redeem and enter the exact code from the table.
4. Tap Redeem, then collect your rewards from the in-game Mailbox.

Use your normal regional game client. The reward-code interface is the in-game Treasure Redeem menu; avoid unofficial web forms that ask for account credentials.

If Treasure Redeem is missing, complete more of the early story and return to the lobby. A code may also be restricted by server region, campaign start time, expiry or previous redemption. Copy the code without spaces and preserve its spelling. A report that a code works on one regional client does not guarantee availability in another.
