NOCOWS is a Diablo Immortal promotion scheduled to end on November 30, 2026. A reproduction of the campaign graphic lists rewards for new and existing accounts, with delivery through in-game mail after reaching level 10. The original publisher post could not be independently retrieved, but the reproduced terms provide a much clearer deadline than the undated strings on general code lists. Some codes may already be deactivated, used up or region-locked.

## Current Diablo Immortal codes

| Code | Reward | Availability |
| --- | --- | --- |
| `NOCOWS` | 1 Legendary Crest, 3 Rare Crests, 1 random Legendary Gear, 6 Aquamarine, 6 Sapphire | Nov 30, 2026; timezone unspecified |

The stated redemption window began November 4. There is no closing hour or timezone on the reproduced terms, so claim the offer well before the last day. A Legendary Crest is included, but the random Legendary Gear does not guarantee a particular equipment slot or item.

## How to redeem the Diablo Immortal code

1. Find your Player ID in the game's Settings under General.
2. Open the [Diablo Immortal redemption site](https://diabloimmortal.com/redeem).
3. Follow the account sign-in and character/server selection prompts, then enter NOCOWS.
4. Check the in-game mailbox on the eligible character after reaching level 10.

The published campaign wording specifies a limit of one redemption per account, shared across its characters. Check the account and server before submitting. If you have only recently started playing, the level requirement matters for delivery even if you have already entered the code.

## What to check if the reward does not arrive

First establish whether the website accepted the offer. If it returned an error, check the code spelling, account selection and campaign window. If redemption succeeded but there is no reward, check the stated level threshold and the mailbox before attempting another submission. The terms do not promise a second allocation to an alternate character.
