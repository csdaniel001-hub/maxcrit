Aniimo gift codes are a quick source of free Glimmer and Aniipod Pro, but the game only hands them out occasionally.

These codes were rounded up on November 25, 2026, from code trackers that list them as active as of their November updates. We have not redeemed them on a MaxCrit account, and some codes may already be deactivated, used up or region-locked, so if one fails, move on to the next. Codes are case-sensitive: copy them exactly as written.

## Active Aniimo codes

| Code | Rewards | Status |
| --- | --- | --- |
| `ANIIMOGIFT` | 10 Glimmer, 20,000 Credits, 10 Growth Flower, 5 Aniipod Pro | Reported active Nov 23 |
| `Aniimo2026` | 20 Glimmer | Reported active Nov 23 |

[GameWith's code guide](https://gamewith.ai/aniimo/en/articles/how-to-redeem-codes), updated November 23, lists both codes with these exact rewards, and Aniimo Tools agrees. Redeemed together, they come to 30 Glimmer, 20,000 Credits, 10 Growth Flower and 5 Aniipod Pro. ANIIMOGIFT carries the Aniipod Pro and most of the value.

## How to redeem Aniimo gift codes

1. From the main menu, open Settings using the gear icon.
2. Select the Account tab.
3. Choose Gift Code Redemption.
4. Enter the code exactly as written, including capitals, and select Redeem.
5. Open Mail and claim your rewards.

A rejected code usually means a typo, a code your account has already used, or a code that has since been switched off.

## Free rewards beyond codes

Gift codes are separate from event rewards. During the Annual Carnival, from November 27, 10:00 to December 1, 12:00 server time, Student I players can claim the free Aniimo Gratitude Gift Box from Shop > Pack. It holds a Departure with the Wind: Collectible Blind Box, 100 Wonder Sugar Crystal and 5 Vein Essence.
